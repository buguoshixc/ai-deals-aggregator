前端样稿 · 4 个方向

都是纯静态展示稿——只有 CSS hover 效果，没有 JS、没有真实筛选与跳转。 用的是真实数据（deals.json 里的实际文案与数字），方便你判断版式扛不扛得住真实内容。

请注意每个样稿都在处理同一个难题：百度千帆那 17 条的优惠文案完全一样， 只有模型名不同。四个稿子给了四种答案——分组标题（A）、分组行 + 续行弱化（B）、 合并成一条 + 模型名平铺（C）、折叠展开（D）。这一条的观感差异，基本就是这个站好不好看的关键。
A

清爽卡片

现代化的信息卡片站，最接近当前版本的升级路径
  • 双列卡片，每张卡完整自洽：优惠 → 描述 → 标签 → 页脚 → 全宽按钮
  • 已核验用左侧绿色边条，23 条人工核验一眼可辨
  • 顶部 4 个数字指标 + 快捷筛选 chip 行（含「只看已核验」）
  • 优惠详情提到描述之前，红色强调块作为第一视觉焦点
  • 同类条目用分组标题分隔，吸收重复文案

B

高密度清单

表格化信息工具，效率优先，一屏看十几条
  • 五列表格：模型 / 优惠内容 / 适用条件 / 有效期 / 核验状态
  • 横向 厂商 facet 条，把国内 12 家厂商摊开成一行，点击即筛
  • 时效独立成列，临近截止直接标红「剩 5 天」
  • 优惠类型用左侧色条区分：免费 / 额度 / 学生 / 限时
  • 重复额度用分组行 + 续行弱化，17 条压成 4 行

C

编辑精选

内容站/杂志感，有主张、有编排，最不像「聚合器」
  • 衬线标题 + 报纸式报头，观感最独特，容易记住
  • 顶部 4 个主题入口（免费额度 / 学生 / 非营利 / 限时），按需求分流
  • 一张大头条卡：左侧讲价值，右侧抬出额度/适用/有效期/领取方式
  • 优惠陈述用编辑体例，关键数字放大成衬线大号
  • 重复额度合并成一条，17 个模型名平铺在下方标签墙

D

开发者控制台

深色 + 等宽字体，面向开发者，工具感最强
  • 左侧固定侧栏导航：12 家国内厂商直接列出来，点击即筛
  • 深色配色+等宽字体，优惠内容做成代码块质感
  • 行式布局：序号 / 正文 / 右侧元数据列（适用、核验状态、按钮）
  • 重复额度用可折叠区块展开 17 个模型名
  • 工具条目整行弱化到 68% 透明度，不抢优惠注意力
