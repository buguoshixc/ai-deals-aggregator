## 1. Google Search Console（URL 前缀属性）

### 1.1 添加属性并拿 token

1. 打开 <https://search.google.com/search-console>，用站点主 Google 账号登录。
2. 「添加资源」→ 选 **网址前缀**（URL prefix），填：
   `https://buguoshixc.github.io/ai-deals-aggregator/`
   （不是「网域」属性 —— 网域属性只能用 DNS 验证，github.io 不给我们域名控制权。）
3. 验证方式选 **HTML 标记**，复制它给的 `content` 值（形如 `abcDEF...`）。

### 1.2 把 token 放进仓库（只改一个文件）

编辑 `scripts/data/site-verification.json`：

```json
"google": {
  "metaName": "google-site-verification",
  "token": "在这里粘贴 GSC 给的 content 值",
  "acquiredAt": "2026-10-26"
}
```

然后本地跑 `npm run build`，确认输出里有：

```
✓ 站点归属验证 meta: google（google-site-verification，token abcd…wxyz）…
```

构建期会把它注入**首页 `<head>`**（`index.html` 的 `<!-- SEO:VERIFICATION:START/END -->` 注入块）；
token 为空时整块不输出、绝不会生成占位 token。提交并发布后，回 GSC 点「验证」。

### 1.3 验证通过后（同一天内做完）

1. **提交 sitemap**：左侧「站点地图」→ 输入 `sitemap.xml` → 提交。
   地址应是 `https://buguoshixc.github.io/ai-deals-aggregator/sitemap.xml`（182 条 URL）。
2. **对下面 10 个 URL 逐个「请求编入索引」**（URL 检查 → 粘贴 → 请求编入索引；一天别超过 ~10 条）：

| # | URL | 为什么要它 |
|---|---|---|
| 1 | `/` | 首页是当前唯一有展示的页面；先把主入口的索引状态确认下来 |
| 2 | `/free-api/` | **答案页 1**：接「免费 API / 免费额度」查询组；也是 `/need/free-api/` 别名页 canonical 的正本 |
| 3 | `/plans/api/` | **答案页 2**：接「API 价格 / 每百万 token」查询组 |
| 4 | `/plans/coding/` | 查询句式标题已改（价格 + 2026 + Claude/Copilot/Cursor） |
| 5 | `/need/free-model/` | 查询句式标题已改（免费模型 + 智谱/硅基流动） |
| 6 | `/need/edu-identity/` | 查询句式标题已改（教育邮箱 + GitHub/Notion/Figma） |
| 7 | `/student/` | 收录基础最好的人群入口之一（12 条） |
| 8 | `/developer/` | 条目最多的人群入口（67 条） |
| 9 | `/category/api/` | API 服务分类入口（36 条，覆盖面最大的一类） |
| 10 | `/changes/` | 每日变化页，`changefreq=daily`，给抓取频率一个理由 |

> 为什么先这 10 条：它们覆盖「首页 → 两个答案页 → 三个人群/分类入口 → 每日变化」，
> 而且都是**已经被站内链接指向的入口页**（不是详情页）。80 个 `/deal/` 详情页数据实测
> 一周一个都进不了前五（门槛 19 PV/周）—— 详情页是数据，不是获客，别浪费索引请求。

3. 之后**每周看一次**「覆盖率 / 网页」：确认「已编入索引」在涨、「已发现但未编入」在降。
   若出现「备用网页（有 canonical 标签）」指向 `/free-api/`、`/student/` 等正本，那是**预期行为**
   （3 个 `/need/*/` 别名页按 v1.8 策略用 canonical 收口，不进 sitemap、不再 noindex）。

## 2. 百度搜索资源平台

### 2.1 添加站点并拿 token

1. 打开 <https://ziyuan.baidu.com>，用站点主百度账号登录 → 用户中心 → **站点管理** → 添加网站。
2. 站点填 `https://buguoshixc.github.io`（百度站点管理按域名收；路径部分在 sitemap 里体现）。
3. 验证方式选 **HTML 标签**，复制 `content` 值（形如 `codeva-XXXXXX`）。
4. 把 token 填进 `scripts/data/site-verification.json` 的 `baidu.token`（`acquiredAt` 写当天），
   `npm run build` 后发布，回平台点「验证」。

> **已知风险（写在这里，别到时候当成 bug）**：百度 HTML 标签验证按「站点首页」检查。
> 如果百度把「站点首页」解析成 `https://buguoshixc.github.io/`（域名根，不是本项目路径），
> 而那个地址不是本仓库发布的页面，验证会失败。两种处置（按顺序试）：
> 1. 先在站点管理里看它回读的「首页」是不是项目路径；是则直接过。
> 2. 若回读的是域名根：百度还提供 **HTML 文件验证** —— 把平台给的文件放到域名根。
>    域名根属于 GitHub 账号的「用户站点」仓库（`buguoshixc/buguoshixc.github.io`），
>    **不在本仓库**；这属于站点主的额外一步，本仓库不做，也不改 `PUBLIC_FILES`（本轮范围）。
> 3. 若两条都不通，把结论记成「百度对 github.io 项目路径暂不可验证」，
>    **第 3/6 周判据改为只看必应 + Google**，不要为此换域名（用户已明确：不换域名）。

### 2.2 验证通过后

1. **资源提交 → 普通收录 → sitemap**：提交
   `https://buguoshixc.github.io/ai-deals-aggregator/sitemap.xml`。
2. **抓取诊断**：对首页与 `/free-api/`、`/plans/api/` 各跑一次，记录「抓取成功 / 状态码 / 下载大小」。
   百度抓取失败时优先看「抓取异常」里的 IP/地区原因，不要先怀疑页面内容。
3. 每周看「索引量」：百度收录通常比 Google 慢，**第 3 周只看索引量是否 > 0 且在上行**。

## 5. 红线（与 `docs/marketing/推广文案.md` §七 同源）

- 不写「全网最全 / 官方合作 / 保证能领到 / 限时最后一天 / 帮你省 XX 元」；
- 不为了收录造「优惠码 / 邀请码」内容（站点原则禁止编码类内容）；
- 不换域名、不做外链长期投入（GitHub Pages 发不出 301，URL 权重不可搬迁）；
- 百度若验证不通，如实写「不可验证」，不伪造 token、不伪造提交记录。
