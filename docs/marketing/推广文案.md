## 一、先确认三件事（发之前）

1. **必须署明「我做的」**。三个平台都吃「作者自荐」这一套，最怕的是伪装成路人推荐 —— 一旦被扒，号比站先废。
2. **文案里的数据要带日期**。写「数据更新到 10-14」，并加一句「具体以官方页为准」，否则三个月后有人翻出来就是打脸素材。
3. **两个平台的外链规则相反，别用同一套处理**：
   - **小红书：正文、评论、标题、图片里都别放网址。** 平台《交易导流违规管理细则》（2025-03-12 生效；2026-09-18 修订版进一步收紧）把「发布其他平台链接、口令、截图、水印、二维码、小程序」列为违规，识别场景明确包含**笔记标题 / 正文 / 图片 / 视频 / 评论**及主页资料，处罚从警告、限流到暂时或永久封号、扣信誉分。
     ⚠️ **所以「把外链放置顶评论」同样是违规动作，不是安全区。**可行做法：正文只写站名（「AI 优惠聚合器」）＋ 自报「GitHub Pages 纯静态站」这一属性，让读者自己搜；不要配「点这里」「私信我」「+V」等任何引导语。
   - **牛客：外链可有条件地贴。** 官方规范允许在文末写「内容来源：XXX」，学习资源类站外链接必须**直接可达**（不得二次关注 / 分享 / 下载 / 付费），但**禁止纯外部链接帖**（含纯宣传性质、毫无实质内容的外链）—— 所以牛客那条帖必须自带干货正文，链接只作补充放文末。
   - 两平台都**禁止帖内图片含二维码**；牛客对「含不必要外部链接」的帖子会取消精华并删帖，小红书对「AI 起号引流带货」有专项治理。

## 七、不要写进文案的话（红线）

| 别写 | 原因 |
|---|---|
| 「全网最全 / 最全没有之一」 | 不可证伪的绝对化用语，且广告法口径下容易被抓 |
| 「官方认证 / 官方合作」 | 站点与厂商无任何合作，写了就是虚假陈述 |
| 「100% 有效 / 保证能领到」 | 额度政策、地区限制、实名门槛都会变，站里本身也标了大量 `unknown` |
| 「限时！最后一天！手慢无」 | 站内数据实测 `expiresAt` 为空的条目很多，多数活动「未标注截止日期」；小红书《营销玩法违规》细则明确禁止「憋单」（制造稀缺 / 限时紧迫感） |
| 「帮你省钱 XX 元」 | 站内不做折算；换算口径一旦被追问就站不住 |
| 「排行榜第一 / 强烈推荐 X」 | 与站点「不排序、不推荐」的设计原则直接冲突，写出去就是自拆招牌 |
| 「点我链接注册 / 用我的邀请码」 | 疑似拉新返利（小红书对「违规招募推广 / 薅羊毛」有明文），且站内卡片主链接指向厂商官方页，**不带任何邀请码** |
| 「私信我发你 / 链接在评论区」 | 小红书导流识别场景含评论与私信，属于明确违规动作 |
