## §3. `dist.baseline/` `dist.synth-fixed/` **绝不会**被带进去（三层，逐层实测）

**① 清单法（主保证）**：上面 8 条之外的路径根本不会进入 `git add` 的视野 —— 没有 `-A`、没有 `.`。

**② 忽略规则（第二层，实测 `git check-ignore -v`）**：

| 路径 | 命中的规则 |
| --- | --- |
| `dist` | `.gitignore:2:dist/` |
| `dist.baseline` | `.git/info/exclude:11:dist.baseline/` |
| `dist.synth-fixed` | `.git/info/exclude:14:dist.synth-fixed/` |

> ⚠️ 后两条来自 **`.git/info/exclude`，这是本 worktree 本地的忽略文件（不入库）** ——
> 换一个 clone 就不存在了。所以第二层只能算"顺手挡一道"，**主保证永远是 ① 的指名清单**。

**③ 实测：连"想加"都加不进去**

```bash
git add --dry-run -- dist.baseline dist.synth-fixed      # 退出码 1，0 条 add 行
# → The following paths are ignored by one of your .gitignore files:
#   dist.baseline
#   dist.synth-fixed
#   hint: Use -f if you really want to add them.
```

**④ 旁证**：`git status --porcelain -uall` 里**顶层 `dist*` 条目 = 0**；
`git ls-files -- dist dist.baseline dist.synth-fixed` → **0 个已跟踪文件**。
（`status` 里有 11 条**文件名含 "dist"** 的条目，全部是证据目录里的文本/JSON ——
