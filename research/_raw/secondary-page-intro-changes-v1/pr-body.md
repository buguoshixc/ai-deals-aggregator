# 二级页首屏去解释化 + 「最近变化」条件化

## 这一轮解决什么

二级标签 / 聚合页（`/student/` `/developer/` `/free-api/` `/need/*` `/category/*` `/vendor/*`）
上两个具体的 UX 问题：

1. **标题下面那段解释性小字**（「拿到手是可以按量消耗的 Token、积分或体验金，不是一个免费档位。」
   「只收来源明说『不需要信用卡』的条目；没写支付方式的条目是『尚未确认』，不在这一页。」……）
2. **页底「最近变化」模块**：没有变化时也占三行、标题把页面名再念一遍、还展示变化系统的基准日与起算日

目标形态：

```
标题 + 条目数 + 数据更新时间

[摘要]  [优惠列表 / 表格]

[最近变化]        ← 只有真的存在相关变化事件时才出现；≤3 条；入口进 /changes/
› 分类说明   展开  ← 更低层级，默认折叠

Footer
```

## 改了什么

### 一、顶部说明整层删除（H13）

* `build-local.js`：删掉 `userIntro → <p class="snote">` 那一层与模板插槽
* 41 条说明逐条处置（**不是**整批搬家）：
  * **39 条进底部折叠** `userNotes` —— 分类边界 / 误解说明 / 数据缺口（例如「来源没提学生身份 ≠ 学生不能用」、
    「『免费档』≠ 全部功能免费」、「只列当前有效的优惠；已结束的条目在历史档案里」）
  * **2 条直接删** —— 两个枢纽页那句「只列出达到门槛的…」已由渲染层的共享句承担，搬过去就是同一句话说两遍
  * **3 条保留** —— 别名页顶部那条「这一页是旧地址……该去哪里」是**导航更正**，不是解释性副标题
    （那三页 noindex）；构建期把它登记成唯一白名单，且要求恰好 1 条、必须带 `aliasnote` 类
* 维护口径没有被删掉：`docs/DESIGN-RULES.md` 的「二级数据页口径归档」早就持有它们，
  并新增一条断言守着「每条按需求页仍保留机器可读 `criteria`」

### 二、「最近变化」改成条件模块（H14）

* 判据只有一条：**本页相关变化事件 ≥ 1 条**，否则 `changesTopicHtml()` **逐字返回空串**
  （不输出标题 / 空态 / 基准日 / 起算日 / 空容器）。日志不可用时雷达本来就是空的 ⇒ 同一处置
* 标题固定 **「最近变化」**（不再注入 `「{页面名}」最近的变化`）；`CHANGES_LABELS.recent` 权威表 + 前端受控副本同源
* 最多 **3 条**（与首页条带同密度），行渲染**复用** `/changes/` 的 `changesRowHtml()` ⇒ 同一件事同一个词，
  且「页面不自己造事件」由同源直接保证；顺序复用 `renderOrderOf()`
* 入口复用既有稳定路由 `/changes/`（不新造 `?tag=`）
* 目录页此前对 `.chgsec/.chgmeta/.chglist/.chgi` **一条样式都没有**（那些规则只存在于 `/changes/` 的页面级 CSS 里，
  这也是它「看起来像一段裸文字」的原因）；本轮补 9 条作用域 `.chgtopic` 规则，全部走 token
* 顺带修掉一处悬空引用：`vendor-page.js` 里「优惠变化见本页上方的「最近变化」块」改为随模块条件化

### 三、顺带修掉两个「扫描面照不到」的真实缺陷

* 构建期两条 `.snote` 扫描用 `/<p class="snote"[^>]*>/`，对 `<p class="snote aliasnote">` **0 命中** ——
  别名页那句里的 `benefitType` 从来没被任何守卫看见（本轮用放宽后的 matcher 复现）。matcher 改成 class token 级，
  补正反例探针，并把那句内部措辞从文案里去掉
* 同一处修复照出 45 个模型详情页正文里的**字面反引号**（`` `supportedModels` ``，`.snote mnone` 容器此前照不到），
  按既有约定改成直接写字面量
