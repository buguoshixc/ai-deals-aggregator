<h2 class="anchor anchorWithStickyNavbar_YAqC" id="date-2026-09-10">Date: 2026-09-10<a href="#date-2026-09-10" class="hash-link" aria-label="Direct link to Date: 2026-09-10" title="Direct link to Date: 2026-09-10">​</a></h2>
<h3 class="anchor anchorWithStickyNavbar_YAqC" id="deepseek-v41-flash-release">DeepSeek-V4.1-Flash Release<a href="#deepseek-v41-flash-release" class="hash-link" aria-label="Direct link to DeepSeek-V4.1-Flash Release" title="Direct link to DeepSeek-V4.1-Flash Release">​</a></h3>
<p>Today, we officially release the DeepSeek-V4.1-Flash model. It is the smallest model in our new architecture family, with native multimodal visual understanding. The new architecture is designed for a higher capability ceiling, faster inference, higher throughput, and scaling to larger models.</p>
<ul>
<li>GPQA Diamond: 90.9</li>
<li>HLE: 36.8 (39.1*)</li>
<li>Codeforces (Rating): 3471</li>
<li>MathArena Apex: 65.6</li>
<li>Terminal-Bench 2.1: 90.6</li>
<li>Terminal-Bench 3.0: 30.0</li>
<li>Terminal-Bench 4.0: 31.2</li>
<li>DeepSWE v1.1: 74.2</li>
<li>ProgramBench: 20.3</li>
<li>NL2Repo-Bench: 65.4</li>
<li>CyberGym: 88.1</li>
<li>SEC-Bench Pro: 62.8</li>
<li>ExploitGym: 15.3</li>
<li>HLE (w/tools): 63.9</li>
<li>Automation-Bench: 54.8</li>
<li>Agents&#x27; Last Exam: 31.8</li>
<li>Chartography (w/tools): 78.9</li>
<li>BabyVision (w/tools): 89.6</li>
<li>ZeroBench-main (w/tools): 49.0</li>
</ul>
<div style="font-size:14px"><p>* Tested only on the pure-text subset of the HLE benchmark set.</p></div>
<b>API changes</b>
<p>DeepSeek V4.1 Flash is now available on the DeepSeek API with native multimodal support. Change the model name to <code>deepseek-flash</code> to call the latest V4.1 Flash model. The previous-generation models V4 Flash and V4 Flash Vision Exp have been retired; for compatibility, the model names <code>deepseek-v4-flash</code> and <code>deepseek-v4-flash-vision-exp</code> are temporarily routed to V4.1 Flash.</p>
<p>In response to user demand, we have decided to continue providing API services for DeepSeek V4 Pro after September 14, 2026, with the billing method remaining unchanged. We will provide further notice should there be any changes. Thank you for your understanding and support!</p>
<b>API pricing adjustment</b>
<p>With the release of DeepSeek-V4.1-Flash, API prices have been reduced accordingly. For details, please refer to <a href="/quick_start/pricing">Models &amp; Pricing</a>.</p>
<p>For more details, please refer to <a href="/news/news260910">this documentation</a>.</p>

<h3 class="anchor anchorWithStickyNavbar_YAqC" id="deepseek-v4-flash-vision-exp-release">DeepSeek-V4-Flash-Vision-Exp Release<a href="#deepseek-v4-flash-vision-exp-release" class="hash-link" aria-label="Direct link to DeepSeek-V4-Flash-Vision-Exp Release" title="Direct link to DeepSeek-V4-Flash-Vision-Exp Release">​</a></h3>
<p>Today, the new multimodal vision understanding model DeepSeek-V4-Flash-Vision-Exp is now available on the DeepSeek API platform. This is an experimental model that can be accessed by setting <code>model=&#x27;deepseek-v4-flash-vision-exp&#x27;</code>.</p>
<ul>
<li>Terminal Bench 2.1: 83.9</li>
<li>NL2Repo: 57.7</li>
<li>DeepSWE: 59.3</li>
<li>DSBench-Hard: 63.6</li>
<li>AutomationBench (Public): 25.7</li>
<li>ApexBench (Pass@1): 36.5</li>
<li>Agents&#x27; Last Exam: 27.3</li>
<li>Chartography: 64.3</li>
<li>ZeroBench (Pass@5): 35.0</li>
</ul>
<div style="font-size:14px"><p>* For the Code Agent text tasks in the public benchmark sets, the DeepSeek family models were tested using the DeepSeek Harness minimal mode as the framework, with the max effort level, topp=0.95, and temperature=1.0; in the ApexBench and Agents&#x27; Last Exam evaluations, the text model DeepSeek-V4-Flash ignores the multimodal elements within them.</p></div>
<p>In terms of pure-text capabilities (agent, reasoning, world knowledge, etc.), DeepSeek-V4-Flash-Vision-Exp is on par with the official DeepSeek-V4-Flash.</p>
<p>On agent benchmarks that require visual understanding, DeepSeek-V4-Flash-Vision-Exp delivers a significant leap over DeepSeek-V4-Flash, bringing its multimodal agent capabilities close to Opus-4.8.</p>
<p>For usage details, please refer to the <a href="/guides/vision">Vision guide</a>.</p>

<h2 class="anchor anchorWithStickyNavbar_YAqC" id="date-2026-08-13">Date: 2026-08-13<a href="#date-2026-08-13" class="hash-link" aria-label="Direct link to Date: 2026-08-13" title="Direct link to Date: 2026-08-13">​</a></h2>
<h3 class="anchor anchorWithStickyNavbar_YAqC" id="deepseek-v4-pro-update">DeepSeek-V4-Pro Update<a href="#deepseek-v4-pro-update" class="hash-link" aria-label="Direct link to DeepSeek-V4-Pro Update" title="Direct link to DeepSeek-V4-Pro Update">​</a></h3>
<p>The GA release of DeepSeek-V4-Pro has been rolled out on the APP, Web, and API. The API calling method remains unchanged — simply set the model name to <code>deepseek-v4-pro</code> to use the latest version.</p>
<b>Significantly enhanced Agent capabilities</b>
<p>The GA version of DeepSeek V4 Pro greatly enhances agent capabilities, with particularly significant performance improvements in production environments.</p>
<ul>
<li>HLE (wo / w tools): 42.7/60.0</li>
<li>Terminal Bench 2.1: 87.9</li>
<li>NL2Repo: 61.5</li>
<li>Cybergym: 83.3</li>
<li>DeepSWE: 62.7</li>
<li>Toolathlon-Verified: 74.1</li>
<li>Agents&#x27; Last Exam: 25.7</li>
<li>AutomationBench (Public): 31.8</li>
<li>DSBench-FullStack: 71.1</li>
<li>DSBench-Hard: 67.2</li>
</ul>
<b>Native support for the Responses API</b>
<p>The DeepSeek API now natively supports the OpenAI Responses API format and is specifically adapted for Codex. Users can refer to the <a href="/quick_start/agent_integrations/codex">official documentation</a> and complete the Codex configuration with a one-click configuration script.</p>
<b>More flexible thinking effort control</b>
<p>The thinking modes of V4-Pro and V4-Flash now support three thinking effort levels: low / high / max. In real-world usage, users can flexibly choose based on task complexity: use low for simple tasks, high for daily Agent tasks, and max for more complex scenarios. For setup instructions, please refer to the official API documentation: <a href="/guides/thinking_mode">Thinking Mode</a>.</p>
<b>API Pricing Adjustment</b>
<p>With the official release of the DeepSeek V4 model family, we will <a href="/quick_start/pricing">update and adjust API pricing</a>. To allocate resources more reasonably, we will adopt peak/off-peak pricing, with off-peak prices set at half of the peak-hour prices, encouraging users to schedule their tasks based on actual usage. The new prices will take effect at 16:00 (UTC Time) on August 16, 2026.</p>
<p>For more details, please refer to <a href="/news/news260813">this documentation</a>.</p>
