## 5. 引文上限这回事（为什么 JSON 里每条只有 3 条引文）

`scripts/lib/provenance.js` 的 `MAX_EVIDENCE_ITEMS = 3`：每条记录最多保留 3 条引文，
超出部分会被 `auditEvidence()` **静默丢弃**。所以：

- `v3.0-adopted-candidates.json` 里每条记录只留最要害的 3 条（且已被试算确认为「丢弃 0 处」）；
- **逐模型**的完整原文引文表就是上面 §4 的表格；
- 原始快照（渲染后的完整正文与 DOM）在 `research/_raw/v3.0-sources/text|domtext/<slug>.txt`，
  任何人可以逐字复核。
