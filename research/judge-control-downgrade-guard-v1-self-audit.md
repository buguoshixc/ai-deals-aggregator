## 4. 失效条件

1. **豁免语义变化**（例如将来有第二条对照也走豁免）⇒ 断言 ③ 的「独立重算污染行数」会把新的污染行算进去；
   若新路径没登记，它就会红 —— 这是设计意图，但读红的人要知道这条断言是**登记制**的守卫。
2. **`--json=` 的消费方**：新增了三个 metrics 键（`layoutControlExemptions` / `…Count` / `…Declared`），
   没有删改任何既有键 ⇒ 读旧键的人不受影响；但把整个 metrics 做**逐字节**基线比对的人会看到差异（新增键）。
3. **历史复跑配方**（`--dir=` 指形态注入副本的那些）现在需要补 `--allow-control-exemption`，否则多一条红（见报告 §4 ⚠️）。
4. **靶页如果哪天又被换成 0 条说明的页**（例如某轮把 `need/free-api/` 的导航更正说明删掉）⇒
   断言 ① 会红并点名 —— 这是本任务想要的，但那时**要改的是靶页，不是这条断言**。
