## 遗留事项（如实）

1. 价格历史当前真实数据只有 **1 次** API 价格变化（`cachedInput 0.2 → 0.1`），套餐价格变化为 **0**；
   其余线是「基线以来无价格变化」的平线。渲染路径与折点样式由合成自测证明，不能靠真实数据证明。
2. 「即将到期」窗口是 **30 天**，与 `/changes/` 的「即将结束（7 天）」是两条独立判据，
   已各写注释，不做合并。
3. 暗色卡面比合同字面值亮一档（见 F4 说明）；如果后续要回到 `#181c22`，必须同时下调 `--bg`
   或放弃 `card/bg ≥1.4` 这条断言，两者不能同时成立。
4. 引文行宽用 `31em` 表达「≈62 字符」，不是字面 `62ch`：`ch` 在本仓是「必须登记的居中阅读列」，
   引文不是阅读列；要改用字面 `62ch` 必须同时把引文改成居中窄列（会破坏左侧竖条的版式）。
5. `expiry.ics` 的 `DTSTAMP` 冻结在数据日期（前一日 16:00Z），因此同一份数据重复构建逐字节一致；
   它不是「构建时刻」。
